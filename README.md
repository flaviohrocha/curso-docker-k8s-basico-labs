# Laboratórios do Curso Docker e Kubernetes Básico

## Spring PetClinic Sample Application

A **Spring PetClinic Sample Application** é uma aplicação de exemplo utilizada para demonstrar tecnologias do ecossistema Spring.  

A aplicação representa o domínio de uma **clínica veterinária**, disponibilizando operações para gerenciamento de **proprietários, animais de estimação, veterinários, tipos de animais, especialidades e visitas**.

O projeto oferece suporte a diferentes bancos de dados, incluindo **H2, HSQLDB, MySQL e PostgreSQL**, permitindo explorar diferentes configurações de execução da aplicação. 

Este repositório utiliza: 
- a versão **REST da Spring PetClinic**, que disponibiliza exclusivamente uma **API REST**, sem interface de usuário própria, documentada com **OpenAPI** e **Swagger UI**.


### Utilização neste repositório

Neste repositório, a Spring PetClinic será utilizada como **aplicação de laboratório para os exercícios práticos de Docker e Kubernetes**.

A Spring PetClinic funciona como uma aplicação realista e suficientemente simples para permitir a prática do ciclo de execução e gerenciamento de aplicações conteinerizadas.
